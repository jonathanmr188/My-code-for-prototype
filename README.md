# My-code-for-prototype

Add initial HTML structure for Warehouse Inventory Management and integrate OpenAPI packages

- Created index.html with a basic layout for the Warehouse Management System, including forms for updating stock and recording sales.
- Added sections for displaying current inventory and sales tracking.
- Introduced project.assets.json and project.nuget.cache to manage dependencies, including Microsoft.AspNetCore.OpenApi and Microsoft.OpenApi packages.
- Included Sales and Inventory System.csproj.nuget.g.targets for NuGet package imports.
- Addressed known vulnerabilities in Microsoft.OpenApi package.
